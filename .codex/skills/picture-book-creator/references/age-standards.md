# 儿童绘本分级控制模板

本文件定义 4 个互斥年龄档位。每个档位的约束直接用于驱动故事文案生成和可读性校验。
年龄段边界**不重叠**——用户选定一个档位后，严格按该档位的参数生成。

---

## 总览（速查表）

| 档位 | 代号 | 每页字数 | 全书页数 | 允许对话 | 允许多线 | 允许抽象词 | 角色上限 |
|------|------|---------|---------|---------|---------|-----------|---------|
| 0-2 岁 | BABY | ≤10 | 6-8 | ✗ | ✗ | ✗ | 1 |
| 2-4 岁 | TODDLER | ≤20 | 8-10 | ✗ | ✗ | ✗ | 2 |
| 4-6 岁 | PRESCHOOL | ≤40 | 10-14 | ✓（简单） | ✗ | ✗ | 3 |
| 6-8 岁 | EARLY-READER | ≤60 | 12-16 | ✓（多角色） | ✓（≤2 线） | ✓ | 4 |

---

## BABY（0-2 岁）

**目标读者**：由家长抱着翻阅，认知启蒙阶段。

### 硬约束

| 参数 | 值 |
|------|------|
| 每页字数 | ≤10 |
| 全书页数 | 6-8 |
| 句式 | 单词 / 拟声词 / 重复短句（≤5 字/句） |
| 对话 | 禁止 |
| 多线并行 | 禁止 |
| 抽象词 | 禁止 |
| 角色数 | 1 个主角 |
| 情节 | 无故事线，围绕单一感官体验（颜色/形状/声音/触感） |
| 翻页逻辑 | 每页 = 一个动作 或 一个物品，节奏均匀 |

### 语言白名单

仅允许：日常物品名、动物名、拟声词、基础动词（看/吃/跑/跳）、颜色词。

### 禁忌

分离焦虑、黑暗场景、怪物、突然惊吓元素。

### 视觉要求

大色块、高对比度、简洁构图、纯色或渐变背景、主体占画面 ≥60%。

### 示例页

```
第 1 页
text: 咕噜咕噜！
scene: 一只圆滚滚的小黄鸭浮在蓝色水面上
action: 小鸭子在水上转圈圈
emotion: 开心
composition: 中景，正面视角，小鸭子居中，文字放在画面底部
```

```
第 2 页
text: 扑通！
scene: 小黄鸭跳进水里溅起水花
action: 小鸭子从岸边跳入水中
emotion: 兴奋
composition: 全景，侧面视角，水花占画面左侧，文字放在右上角
```

## TODDLER（2-4 岁）

**目标读者**：开始自主翻书，喜欢重复和可预测的结构。

### 硬约束

| 参数 | 值 |
|------|------|
| 每页字数 | ≤20 |
| 全书页数 | 8-10 |
| 句式 | 简单句（≤10 字/句），重复结构为主 |
| 对话 | 禁止（用转述代替） |
| 多线并行 | 禁止 |
| 抽象词 | 禁止 |
| 角色数 | ≤2 |
| 情节 | 单一主线，简单因果（做了 A → 发生了 B） |
| 翻页逻辑 | 重复结构推进，末页小惊喜或温馨收尾 |

### 语言白名单

在 BABY 基础上增加：基础形容词（大/小/多/少/快/慢）、方位词（上/下/里/外）、简单动词短语。

### 禁忌

暴力、惩罚性结局、负面结果未被修复。

### 视觉要求

主体突出、背景简洁、每页单一焦点、角色造型圆润。

### 关键句式模板（重复结构）

```
[主角] + [动作] + [对象A]。
[主角] + [动作] + [对象B]。
[主角] + [动作] + [对象C]。
→ 末页打破重复，制造惊喜。
```

### 示例页

```
第 3 页
text: 小兔找到了苹果。红红的苹果！
scene: 草地上，小白兔蹲在一个大红苹果旁边
action: 小兔子低头看着苹果，前爪碰了碰
emotion: 好奇
composition: 中景，俯视 30°，苹果在画面中央偏左，文字放在右侧空白处
```

```
第 4 页
text: 小兔找到了香蕉。弯弯的香蕉！
scene: 小白兔站在一棵小树旁，树上挂着一根香蕉
action: 小兔子伸手够香蕉
emotion: 开心
composition: 中景，正面视角，香蕉在画面上方，文字放在底部
```

## PRESCHOOL（4-6 岁）

**目标读者**：能跟随完整故事，开始理解角色情感和因果关系。

### 硬约束

| 参数 | 值 |
|------|------|
| 每页字数 | ≤40 |
| 全书页数 | 10-14 |
| 句式 | 短句 + 简单对话（≤15 字/句） |
| 对话 | 允许，限 2 人一问一答 |
| 多线并行 | 禁止 |
| 抽象词 | 禁止（用具体行为代替抽象概念） |
| 角色数 | ≤3 |
| 情节 | 起承转合完整，1 个核心冲突 + 1 个解决方案 |
| 翻页逻辑 | 中段设悬念驱动翻页，高潮在 60-75% 位置 |

### 语言白名单

在 TODDLER 基础上增加：常用形容词、具体情感词（开心/难过/害怕/生气）、简单连接词（然后/可是）。

### 禁忌

复杂隐喻、成人化表达、说教语气、开放式负面结局。

### 视觉要求

场景可以丰富，但每页有明确视觉焦点，背景不喧宾夺主。

### 对话格式约束

```
"[角色A台词]" [角色A名字] + [说话动作]。
"[角色B台词]" [角色B名字] + [回应动作]。
```

### 示例页

```
第 5 页
text: "我够不到那朵花。"小猫踮起脚尖，尾巴翘得高高的。
scene: 花园里，橘色小猫在一丛高高的向日葵前踮脚
action: 小猫伸长前爪试图够到最高的向日葵
emotion: 着急但努力
composition: 仰视，小猫在画面下方 1/3，向日葵延伸到画面顶部，文字放在画面左下角
```

```
第 6 页
text: 大熊走过来，轻轻地把花摘下来递给小猫。"给你！"
scene: 棕色大熊站在小猫旁边，手中拿着一朵向日葵递给小猫
action: 大熊弯腰递花，小猫双爪接住
emotion: 大熊温柔，小猫惊喜
composition: 中景，平视，两个角色并排居中，文字放在画面顶部
```

## EARLY-READER（6-8 岁）

**目标读者**：开始自主阅读，能理解复杂情感和多角色关系。

### 硬约束

| 参数 | 值 |
|------|------|
| 每页字数 | ≤60 |
| 全书页数 | 12-16 |
| 句式 | 复合句 + 多角色对话（≤20 字/句） |
| 对话 | 允许，可多角色（≤3 人） |
| 多线并行 | 允许，≤2 条线索 |
| 抽象词 | 允许（勇气/友谊/信任/责任） |
| 角色数 | ≤4 |
| 情节 | 多角色互动，1-2 个转折点 |
| 翻页逻辑 | 章节感，高潮与舒缓交替 |

### 语言白名单

在 PRESCHOOL 基础上增加：抽象情感词、因果连接词（虽然...但是 / 因为...所以 / 如果...就）、心理描写短句。

### 禁忌

过度暴力、歧视性内容、恐怖元素、无解的负面结局。

### 视觉要求

可以有复杂场景和细节，支持多层次构图、远近景结合。

### 示例页

```
第 7 页
text: 虽然前面的山洞黑漆漆的，但小狐狸想起了妈妈的话："勇敢不是不害怕，是害怕了还要往前走。"他深吸一口气，迈出了第一步。
scene: 阴天的山脚下，一只橙色小狐狸站在山洞入口，洞内幽暗，洞外有温暖的光
action: 小狐狸一只前爪迈进洞口，回头看了一眼身后的光亮
emotion: 紧张但坚定
composition: 全景，小狐狸在画面中央偏右，洞口形成明暗对比的框架构图，文字放在画面底部横排
```

## 可读性校验清单

阶段 4（可读性测试）使用以下清单逐项检查。每项标注 ✓ 或 ✗，不通过则回退修改。

### 语言校验

- [ ] 每页字数 ≤ 档位上限
- [ ] 每句字数 ≤ 档位句长上限
- [ ] 无超档词汇（对照该档位语言白名单）
- [ ] 无成人化表达或说教语气
- [ ] 对话使用符合档位约束（BABY/TODDLER 禁止对话）
- [ ] 抽象词使用符合档位约束（仅 EARLY-READER 允许）

### 情节校验

- [ ] 故事在目标页数范围内自然完成
- [ ] 情节连贯，无逻辑跳跃
- [ ] 冲突和解决方式适龄
- [ ] 结尾积极温暖
- [ ] 多线并行符合档位约束（仅 EARLY-READER 允许，且 ≤2 线）
- [ ] 角色数 ≤ 档位上限

### 节奏校验

- [ ] 翻页有驱动力（悬念/好奇心/重复结构）
- [ ] BABY/TODDLER 档运用了重复句式
- [ ] 高潮位置在全书 60-75% 处
- [ ] 节奏无过快（场景跳跃）或过慢（信息重复无推进）

### 视觉可画性校验

- [ ] 每页场景具体可画
- [ ] 无过于抽象难以视觉化的描述
- [ ] 角色动作具体明确
- [ ] 连续页面场景变化不超过 2 次大场景切换

### 安全行为校验

所有档位通用。故事中不得出现角色进行以下危险行为的场景，也不得以正面、有趣、令人向往的方式呈现这些行为：

- [ ] 无玩火、点火、靠近明火场景
- [ ] 无玩刀、剪刀、尖锐物品场景
- [ ] 无攀爬高处（爬树、爬窗、爬梯子无人看护）场景
- [ ] 无独自靠近水域（河边、池塘、泳池）场景
- [ ] 无独自过马路、在车道玩耍场景
- [ ] 无触碰电源插座、电器场景
- [ ] 无吞食非食物物品（药品、小零件、植物）场景
- [ ] 无独自离家、跟陌生人走的场景
- [ ] 无从高处跳下（阳台、桌子、台阶以外的高度）场景
- [ ] 无模仿成人使用危险工具（锤子、锯子、打火机）场景
- [ ] 无戏弄或激怒动物（拉尾巴、追逐蜂巢等）场景
- [ ] 无角色因危险行为获得奖励或正面结果的情节
